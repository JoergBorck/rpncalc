# Bugs (B)

Dateien zu Bugs (B) aus dem [Backlog](../../backlog.md), benannt nach der ID (Vorlage: [template.md](../template.md)).
Sie dienen dem Nachweis, nicht der Beschreibung des Systems: Offene Einträge stehen im
[Inhaltsverzeichnis](../README.md), erledigte und abgelehnte fallen dort heraus, ihre Datei bleibt hier erhalten
(process/workflow.md, „Anforderungen“).
