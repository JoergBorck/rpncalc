# Tests und Reviews

Ergebnisse von Tests und Reviews, damit sie nachvollziehbar bleiben (process/workflow.md, „Tests und Reviews“).

| Ordner | Inhalt | committet |
|---|---|---|
| `protocols/` | Protokolle von Tests von Hand, z.B. auf dem Handy oder auf der Prüfseite | ja |
| `reviews/` | Ergebnisse von Reviews und Recherchen (R-Einträge), wenn sie über den Backlog-Eintrag hinausgehen | ja |
| `preview/` | erzeugte Seiten und Bilder: Prüfseite der Hilfe (`dart run tool/hilfe.dart`), Vorschau des App-Symbols (`flutter test tool/symbol_test.dart` in `app/`) | nein |

Dateinamen: `JJJJ-MM-TT_id_thema.md`, z.B. `2026-11-06_ta-1_phone.md` zu TA-1. Der Eintrag im Backlog verweist
auf die Datei.
